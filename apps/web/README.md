# apps/web — pilot UI (M7 minimum)

The minimum pilot workflow in 8 screens, over `/api/v1` only:
1. **Login** — Supabase Auth (email + password, publishable key); in LOCAL mode, a demo token.
2. **Project** — the organization; create or open a project with its client; the project team.
3. **Room** — a rectangular kitchen: width along wall A, depth, height, wall thickness; no openings.
4. **Base cabinets** — KIT_BASE_STANDARD only: add, set width, position, arrange the run, remove.
5. **Preview** — 2D plan, the wall A elevation and a 3D axonometric view of the API's resolved model.
6. **Validation** — BLOCKERs, warnings and passed checks; the APPROVAL run; submit → approve → lock.
7. **Outputs** — BOM, BOQ, Pricing, Quotation and execution drawings, generated by the API's engines.
8. **Issue** — the existing issue workflow: quotation (Sales, with a hand-over code from Costing) and drawings (Design Head). Issued PDFs can be downloaded.

**No business calculation happens here.** ESLint forbids importing engines, persistence, storage or database code. All geometry, validation, quantities, prices and totals are shown exactly as the API returns them.

| Command | Purpose |
|---|---|
| `pnpm pilot:demo` | LOCAL: API + UI + rehearsal data. Open http://127.0.0.1:5173 and paste a token from `.pilot/tokens/` |
| `pnpm web:dev` | UI only. Proxies `/api` to `LINTEL_API_URL` (default http://127.0.0.1:3000) |
| `pnpm web:build` | Static build (`apps/web/dist`) |
| `pnpm --filter @lintel/web api:types` | Regenerate `src/api/schema.d.ts` from `apps/api/openapi/openapi.json` |
| `pnpm pilot:ui-e2e` | Browser walkthrough of all 8 screens against a running `pilot:demo` (Playwright + Chromium) |

| Variable (build time) | Meaning |
|---|---|
| `VITE_APP_ENV=local` | LOCAL demo sign-in (paste a token). Otherwise Supabase Auth |
| `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` | The Supabase project URL and its **publishable** key. Never a secret key |
| `LINTEL_API_URL`, `WEB_PORT` | Dev / preview server: the API to proxy, and the port |
