# database/seed

Intentionally empty. Migrations seed only schema-level registries: roles, actions, default role grants, and the 12
construction and 6 planning variable **codes**. The ManufacturingStandard registry is empty.

No production values are seeded: no construction, planning or manufacturing values, no rates, no tax data, no Hettich
data. Production values enter only through intake → DRAFT → IN_REVIEW → APPROVED.
