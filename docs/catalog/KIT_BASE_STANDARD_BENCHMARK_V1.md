## Result of benchmark research (2026-09-26)

**No field has a verified public benchmark yet.** Every field below reads
`NO VERIFIED PUBLIC BENCHMARK FOUND`.

Reason: the research was run from the Lintel Design OS build environment, whose network policy blocked
every page fetch (hosts refused included `www.hettich.com`, `web.hettich.com`, `publications.blum.com`,
`www.blum.com`, `d2.blum.com`, `awinet.org`, `www.finewoodworking.com`, `www.popularwoodworking.com`).
Search-engine result summaries were returned, but a summary is not the source text: it cannot be quoted or
verified, and several pointed to forums, retailer blogs or vendor pages, which do not meet the source rules.
Therefore **no value has been recorded and none has been inferred**. Unverified numbers seen in summaries are
deliberately not reproduced here.

### Source rules for a value to be recorded
1. The value must be read from a page actually fetched, with a verbatim quote (≤ 40 words).
2. Source URL, publisher, source type and fetch date must be recorded.
3. Preferred sources: hardware manufacturer technical documentation (Blum, Hettich, Häfele, Grass, Salice),
   published standards / trade associations (e.g. AWI), then reputable trade publications. Forums, blogs,
   marketplaces and AI-generated pages are excluded.
4. Confidence: HIGH (manufacturer / standard, explicit, directly applicable), MEDIUM (reputable publication,
   explicit), LOW (explicit but context differs, e.g. face-frame cabinets).
5. Imperial values are shown with their original and a converted mm value, marked as converted.
6. Conflicting sources are listed separately; values are never averaged or derived.

Allow these hosts in the environment's network access settings (or run the research where they are reachable),
then re-run the research with the rules above: `www.hettich.com`, `web.hettich.com`, `publications.blum.com`,
`www.blum.com`, `www.hafele.com`, `awinet.org`, `www.finewoodworking.com`, `www.popularwoodworking.com`,
`www.woodsmith.com`.
